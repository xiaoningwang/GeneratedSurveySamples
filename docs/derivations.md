# 理论公式的推导与计算口径

本说明对应三稿修改版第三部分及式（15）。P表示目标分布，Q表示生成分布；预测函数f固定，或条件于独立训练结果。下列代数结论、方差结论与区间近似分别说明。

## 式（1）：联合分布的分解

按条件概率定义，P(X,Y)=P_X(X)P(Y|X)，Q同理。P_X与Q_X描述人群构成，条件分布描述同类人如何回答。对连续X，应将乘法理解为相应密度或条件分布分解。

## 式（2）：两类均值偏差

设目标组比例p_h、真实组均值mu_h，生成组比例q_h、生成组均值nu_h。由全期望公式，mu=sum(p_h*mu_h)，mu_G=sum(q_h*nu_h)。加减sum(q_h*mu_h)，得

```math
\mu_G-\mu
=\sum_h(q_h-p_h)\mu_h+\sum_hq_h(\nu_h-\mu_h).
```

第一项是样本结构偏差，第二项是条件回答偏差。令b_h=nu_h-mu_h；完全联合分组校准将q改为p后，均值偏差为sum(p_h*b_h)。某个p_h>0的组没有生成回答时，该组nu_h不能由本批记录估计，完全联合分组校准不成立。

正文假设计算：p=(0.5,0.5)，q=(0.75,0.25)，mu_h=(0.4,0.2)，nu_h=(0.3,0.3)。真实均值0.3，生成均值0.3；样本结构偏差0.25×0.4−0.25×0.2=0.05；条件回答偏差0.75×(−0.1)+0.25×0.1=−0.05。两项抵消，女性减男性的差值却由0.2变为0。

## 式（3）—（4）：群体差值

```math
\Delta_{ab}^G-\Delta_{ab}
=(\nu_a-\nu_b)-(\mu_a-\mu_b)=b_a-b_b.
```

sum(p_h*b_h)=0只约束一个加权平均，不要求各b_h相同。因此总体校准偏差为零不能推出群体差值偏差为零。表6中的差值、偏差和图2由该式直接计算。

## 式（5）：生成均值的均方误差

对独立同分布的m条生成回答，E(bar Y*)=mu_G，Var(bar Y*)=sigma_G²/m。由MSE=方差+偏差平方，

```math
\operatorname{MSE}(\bar Y^*;\mu)
=E[(\bar Y^*-\mu_G+\mu_G-\mu)^2]
=\frac{\sigma_G^2}{m}+(\mu_G-\mu)^2.
```

交叉项期望为零。若回答相关，方差为m^(-2)乘所有单条方差与协方差之和，不能沿用独立情形的缩减速度。

## 式（6）：校准约束

标准化权数满足sum(w_j)=1、sum(w_j*a(X_j*))=E_P[a(X)]。这些方程约束辅助特征的加权均值。联合组指示变量作为a时，可匹配完整组比例；只使用年龄和性别各自的指示变量时，只匹配边际比例。校准不更改Y_j*，因此不能单凭这些约束推出组内回答正确。

## 式（7）—（8）：残差校正的期望与方差

设n个独立真实观测来自P，M个独立无标签协变量来自P_X，两组独立。记e=Y−f(X)。则

```math
E(\hat\mu_{PP}\mid f)
=E_P[f(X)]+E_P[Y-f(X)]=E_P[Y].
```

由两组样本独立，

```math
\operatorname{Var}(\hat\mu_{PP}\mid f)
=\frac{\operatorname{Var}_P[f(X)]}{M}
+\frac{\operatorname{Var}_P[Y-f(X)]}{n}.
```

若目标预测平均可由已知分布精确计算，第一项为零。此时与n条真实回答直接估计相比，方差之比为Var(Y−f)/Var(Y)。而Var(Y−f)=Var(Y)+Var(f)−2Cov(Y,f)，故精度改善取决于2Cov(Y,f)>Var(f)，不由预测均值是否接近真实均值单独决定。主模拟的variance_reduction_pct使用重复估计的经验方差计算。

## 式（9）：错误预测分布的剩余偏差

将预测平均改在Q_X下计算，真实残差仍来自P：

```math
E(\hat\mu_{Q,PP})-\mu
=E_{Q_X}[f(X)]+E_P[Y-f(X)]-E_P[Y]
=E_{Q_X}[f(X)]-E_{P_X}[f(X)].
```

在分组模拟中，该值为sum((q_h−p_h)*f_h)。程序同时核对模拟偏差与这一理论值。

## 式（10）：组内校正

对每个g，在该组目标协变量分布下求预测平均bar f_g，再加真实组内残差平均。组内抽样有代表性时，期望为mu_g。两组校正均值相减估计Delta_ab。若组内f恒等于c_g，则c_g+mean(Y−c_g)=mean(Y)，校正恰好退化为真实组均值。

## 式（11）：部分生成数据的方差合并

正文引用Reiter（2003）对适当部分生成数据的合并规则：L份数据的完整数据方差估计平均为bar u，参数估计之间的样本方差为b_L，合并方差T_L=bar u+b_L/L。L份适当生成结果的平均使生成间变异按L缩减，真实调查的不确定性仍由完整数据方差部分体现；适用条件及完整推导以正文参考文献[23]为依据。

该引用规则没有用于本研究API置信区间。API三次二元回答先取平均形成固定预测，后续按真实残差和式（15）估计方差。

## 式（12）—（13）：性能指标

每次重复得到估计值和区间。对固定真值theta，覆盖指示量为1(theta在区间内)，R次均值即经验覆盖率C；区间长度的均值即W。若重复独立，则覆盖指示量为伯努利变量，C的方差为C_true*(1−C_true)/R，代入C得到蒙特卡洛标准误。R=2000、覆盖率0.95时，标准误约0.004873，即0.4873个百分点。

模拟偏差是mean(theta_hat−theta)，RMSE是sqrt(mean((theta_hat−theta)²))。群体区间因组内观测不足而不可构造时，覆盖指示记为0，仍保留在R次分母内；偏差、RMSE和平均宽度同时标注是在可估计重复中计算。

## 式（14）：固定生成组数量的方差

设第h组生成数量m_h固定，各组独立，二元回答样本比例bar Y_h。调整后的组权重为t_h，则估计为sum(t_h*bar Y_h)。伯努利样本方差的无偏估计为m_h*bar Y_h*(1−bar Y_h)/(m_h−1)，除以m_h后即组均值方差估计。因此

```math
\widehat V_G=\sum_h t_h^2\frac{\bar Y_h(1-\bar Y_h)}{m_h-1}.
```

直接生成、边际校准和联合分组校准分别代入q、迭代比例拟合后的组比例和p。此式估计生成随机波动，不包含条件回答偏差。程序使用估计值±1.96标准误构造正态近似区间，实际覆盖率由重复模拟检验。

## 式（15）：固定经验有限总体的方差

固定N=559个真实回答及预测f_i，真实残差e_i=Y_i−f_i。预测总体均值已知，简单随机不放回抽n条残差：

```math
\hat\mu=\frac1N\sum_{i=1}^Nf_i+\bar e_s,
\qquad E_s(\hat\mu)=\bar f_N+\bar e_N=\bar Y_N.
```

有限总体残差方差S_e²以N−1为分母，SRS样本均值方差为(1−n/N)*S_e²/n；用样本残差方差s_e²替代，得到正文式（15）。两个不重叠群体在给定组内样本量时分别使用(1−n_g/N_g)*s_eg²/n_g，差值方差为两组之和。代码要求两个组均至少2条；按实际失败次数报告覆盖率。
